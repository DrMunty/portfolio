Fittë

A training and coaching app. A questionnaire builds the plan, a weekly calendar schedules it and a guided workout with a rest timer runs each session. Clients can find and hire a coach, who builds their routines and talks to them in a chat with photos.

Built alone as the final project of the UPF bootcamp: more than 280 merged pull requests, one branch per feature, CI on every one.

  • Angular
  • Ionic
  • Capacitor
  • NestJS
  • Prisma
  • PostgreSQL
  • GitHub Actions
